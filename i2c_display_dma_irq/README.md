# I2C, DMA and Interrupt excercise

The goal is to put the Matrix movie effect on an I2C display. Initially by just writting the commands via the CPU. 
Afterwards DMA + interrupt can be enabled.

## Display
AZDelivery 1.3 inch OLED Display 128x64 pixels using the SH1106 controller, see [datasheet](../docs/sh1106_datasheet.pdf)
